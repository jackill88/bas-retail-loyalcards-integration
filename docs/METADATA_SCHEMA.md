# Опис об'єктів метаданих для конфігуратора BAS

> Повний опис довідників: [CATALOGS_SCHEMA.md](CATALOGS_SCHEMA.md)

## Справочник: LC_КартыLoyalCards

```
Синонім: Карти Loyal Cards
Призначення: зв'язок контрагента BAS ↔ wallet-картка в loyal.ws

Реквізити:
  - Владелец              : СправочникСсылка.Контрагенты
  - ДисконтнаяКарта       : СправочникСсылка.ИнформационныеКарты
  - SerialNumber          : Рядок(50)     — UUID з QR (унікальний)
  - PassTypeIdentifier    : Рядок(100)
  - MemberId              : Рядок(20)     — номер на картці (унікальний)
  - Телефон               : Рядок(20)
  - URL                   : Рядок(500)
  - Статус                : LC_СтатусыКартыLoyalCards
  - УровеньЛояльности     : LC_УровниЛояльности
  - ДатаВыпуска           : Дата
  - ДатаПоследнейСинхронизации : Дата

Модулі:
  src/Catalogs/LC_КартыLoyalCards/ObjectModule.bsl
  src/Catalogs/LC_КартыLoyalCards/ManagerModule.bsl
```

```
Вид регістра: Залишки
```

## Регістр відомостей: LC_ПартииБонусов

```
Періодичність: Неперіодичний
Режим запису: Підчинення регістратору

Виміри:
  - ПартияБонусов       : СправочникСсылка.LC_ПартииБонусов  (ведучий)

Реквізити:
  - Контрагент          : СправочникСсылка.Контрагенты
  - ДокументОснование   : ДокументСсылка (складений тип: ЧекККМ, Возврат...)
  - ДатаНачисления      : Дата
  - ДатаАктивации       : Дата
  - ДатаСгорания        : Дата
  - СуммаНачислена      : Число(15,2)
  - УровеньЛояльности   : СправочникСсылка.LC_УровниЛояльности
  - Активирована        : Булево
  - Сгорела             : Булево
```

## Регістр відомостей: LC_ОчередьСинхронизацииLoyalCards

```
Періодичність: Неперіодичний

Виміри:

Ресурси / реквізити:
  - ДатаИзменения       : Дата
  - ДоступныйБаланс     : Число(15,2)

```
