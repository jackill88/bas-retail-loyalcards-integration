# Справочники (довідники) — опис для конфігуратора BAS

---

## LC_КартыLoyalCards

**Синонім:** Карти Loyal Cards  
**Призначення:** локальне зберігання зв'язку між контрагентом BAS і wallet-карткою в сервісі LOYAL CARDS.  
**Власник:** не підпорядкований (ієрархія відсутня).

### Налаштування довідника

| Властивість | Значення |
|-------------|----------|
| Довжина коду | 9 |
| Тип коду | Рядок |
| Довжина найменування | 150 |
| Автонумерація | Так |
| Унікальність | SerialNumber, MemberId (індекси) |
| Підпорядкування | Ні |

### Реквізити

| Ім'я | Синонім | Тип | Обов'язковий | Опис |
|------|---------|-----|--------------|------|
| `Владелец` | Власник (контрагент) | `СправочникСсылка.Контрагенты` | Так | Покупець у BAS |
| `ДисконтнаяКарта` | Дисконтна картка BAS | `СправочникСсылка.ИнформационныеКарты` | Ні | Зв'язок зі штатною карткою |
| `SerialNumber` | Serial Number | `Рядок(50)` | Так | UUID картки в Loyal Cards (з QR) |
| `PassTypeIdentifier` | Pass Type Identifier | `Рядок(100)` | Так | Ідентифікатор типу pass (з налаштувань) |
| `MemberId` | Номер картки | `Рядок(20)` | Так | Номер на картці / штрихкод (EAN-13) |
| `Телефон` | Телефон | `Рядок(20)` | Ні | Нормалізований 380XXXXXXXXX |
| `URL` | Посилання на картку | `Рядок(500)` | Ні | URL для встановлення в Wallet |
| `Статус` | Статус | `ПеречислениеСсылка.LC_СтатусыКартыLoyalCards` | Так | Активна / Неактивна |
| `УровеньЛояльности` | Рівень лояльності | `СправочникСсылка.LC_УровниЛояльности` | Ні | Поточний рівень |
| `ДатаВыпуска` | Дата випуску | `Дата` | Ні | Коли картку створено в API |
| `ДатаПоследнейСинхронизации` | Дата останньої синхронізації | `Дата` | Ні | Коли balance оновлено в API |
| `УстановленаВApple` | Встановлена в Apple Wallet | `Булево` | Ні | З API (installed.apple) |
| `УстановленаВGoogle` | Встановлена в Google Wallet | `Булево` | Ні | З API (installed.android) |

### Індекси

| Ім'я | Поля | Унікальний |
|------|------|------------|
| `ПоSerialNumber` | SerialNumber | Так |
| `ПоMemberId` | MemberId | Так |
| `ПоВладельцу` | Владелец | Ні (може бути кілька карток, але зазвичай 1 активна) |
| `ПоТелефону` | Телефон | Ні |

### Форми

| Форма | Призначення |
|-------|-------------|
| `ФормаЭлемента` | Перегляд/редагування картки |
| `ФормаСписка` | Список карток з відбором за контрагентом, телефоном |
| `ФормаВыбора` | Вибір картки в документах |

### Модулі

```
src/Catalogs/LC_КартыLoyalCards/
├── ObjectModule.bsl    — перевірки при записі
└── ManagerModule.bsl   — пошук, створення з API
```

### Зв'язки з іншими об'єктами

| Об'єкт | Зв'язок |
|--------|---------|
| `Справочник.Контрагенты` | `Владелец` |
| `Справочник.ИнформационныеКарты` | `ДисконтнаяКарта` |

## LC_УровниЛояльности

**Синонім:** Рівні лояльності  
**Призначення:** правила нарахування, списання, активації та знижки для груп клієнтів.

### Реквізити

| Ім'я | Тип | За замовчуванням | Опис |
|------|-----|------------------|------|
| `ПроцентНачисления` | Число(5,2) | 5 | % нарахування від грошової частини |
| `МаксимальныйПроцентСписания` | Число(5,2) | 20 | Макс. % списання від чека |
| `ДнейДоАктивации` | Число(3,0) | 14 | Затримка активації |
| `МесяцевДействия` | Число(2,0) | 4 | Термін після активації |
| `ПроцентСкидки` | Число(5,2) | 0 | Для відображення на картці (discount) |
| `ЭтоVIP` | Булево | Ложь | Прапорець VIP |

### Попередньо визначені елементи

| Код | Найменування | ПроцентНачисления | МаксСписание | ПроцентСкидки |
|-----|--------------|-------------------|--------------|---------------|
| `000000001` | Стандарт | 5 | 20 | 5 |
| `000000002` | VIP | 5 | 20 | 10 |

## LC_ПартииБонусов

**Синонім:** Партії бонусів  
**Призначення:** елемент довідника = одна партія нарахованих бонусів (для FIFO і регістру накопичення).  
**Створюється програмно** при проведенні чека.

### Реквізити

| Ім'я | Тип | Опис |
|------|-----|------|
| `Владелец` | Контрагенты | Власник бонусів |
| `ДокументОснование` | ДокументСсылка | Чек, за яким нараховано |
| `СуммаНачислена` | Число(15,2) | Початкова сума |
| `Код` | Рядок(36) | UUID (автогенерація) |

> Дати активації/згоряння зберігаються в регістрі відомостей `LC_ПартииБонусов` (однойменний з довідником — типовий патерн 1С: довідник = вимір, регістр = деталі).
