# Перерахування: LC_ВидыБонусныхОпераций

**Синонім:** Види бонусних операцій

| Значення | Синонім |
|----------|---------|
| `Начисление` | Нарахування |
| `Списание` | Списання |
| `Активация` | Активація |
| `Сгорание` | Згоряння |
| `ОтменаНачисления` | Скасування нарахування |
| `ОтменаСписания` | Скасування списання |
| `ВозвратСписания` | Повернення списання |

Використовується як вимір регістру `LC_БонусныеБаллыОборот`.
