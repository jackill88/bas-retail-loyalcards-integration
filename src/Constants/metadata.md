# Константи інтеграції Loyal Cards

Створити в конфігураторі як окремі константи (або одну структуровану — за бажанням).

| Ім'я | Синонім | Тип | За замовчуванням |
|------|---------|-----|------------------|
| `LC_АдресСервераLoyalCards` | Адреса сервера Loyal Cards | `Рядок(255)` | `https://loyal.ws` |
| `LC_EmailLoyalCards` | Email для API | `Рядок(100)` | |
| `LC_ПарольLoyalCards` | Пароль для API | `Рядок(100)` | *(прихований)* |
| `LC_PassTypeIdentifier` | Pass Type Identifier | `Рядок(100)` | |
| `LC_TemplateId` | Template ID | `Рядок(100)` | |
| `LC_OrganisationId` | Organisation ID | `Рядок(50)` | |
| `LC_ТаймаутЗапросаСек` | Таймаут запиту (сек) | `Число(3,0)` | `30` |
| `LC_ИспользоватьИнтеграциюLoyalCards` | Використовувати інтеграцію | `Булево` | `Ложь` |

Читання: `LC_ОбщегоНазначения.ПолучитьНастройкиИнтеграции()`.

## Форма констант

Рекомендується створити загальну форму **«Налаштування Loyal Cards»** з усіма полями та кнопкою «Перевірити з'єднання».
