# Регістр відомостей: LC_ТокеныLoyalCards

**Синонім:** Токени Loyal Cards  
**Призначення:** кеш JWT-токена авторизації API (уникнення зайвих запитів login).

## Структура

| Поле | Тип | Опис |
|------|-----|------|
| *(без вимірів — однозаписний)* | | |
| `Токен` | Рядок(2000) | JWT без префікса Bearer |
| `ДатаИстечения` | Дата | Термін дії кешу |

> Реалізація: неперіодичний регістр без вимірів (один запис) або з виміром `Организация` за потреби мультитенантності.

## Модуль менеджера

`ManagerModule.bsl` — `ПолучитьТокен()`, `СохранитьТокен()`, `ОчиститьТокен()`.
