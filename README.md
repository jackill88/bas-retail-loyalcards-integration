# BAS × LOYAL CARDS — інтеграція бонусної програми

BAS Роздрібна торгівля для України виступає **керуючою системою** для нарахування/списання бонусів. LOYAL CARDS API використовується лише для відображення балансу на wallet-картці.

- [Чеклист об'єктів метаданих](docs/METADATA_CHECKLIST.md) ← **повний перелік**
- [Схема метаданих](docs/METADATA_SCHEMA.md)

## Ключові регістри

| Регістр | Тип | Призначення |
|---------|-----|-------------|
| `LC_БонусныеБаллыКлиентов` | Накопичення (залишки) | Облік бонусів по партіях і станах |
| `LC_БонусныеБаллыОборот` | Накопичення (обороти) | Історія операцій |
| `LC_ПартииБонусов` | Відомості | Дати активації/згоряння, FIFO |
| `LC_ОчередьСинхронизацииLoyalCards` | Відомості | Черга sync balance → API |

## Порядок обробки

```
Документ (ЧекККМ / Повернення / Регламент)
    → рухи по регістрах BAS
    → LC_СинхронизацияLoyalCards
    → PUT balance в loyal.ws
```

## Модулі

```
src/CommonModules/
├── LC_БонуснаяПрограммаСервер   — рухи по регістрах
├── LC_СинхронизацияLoyalCards   — sync після рухів
├── LC_ИнтеграцияЧекККМ          — проведення документів
├── LC_БонуснаяПрограммаКлиент   — UI каси
├── LC_LoyalCardsAPI             — HTTP-клієнт
└── LC_ОбщегоНазначения           — допоміжні функції
```

## Впровадження

1. Створити об'єкти метаданих згідно плану
2. Скопіювати код модулів у конфігуратор (режим розширення)
3. Налаштувати константи API
4. Заповнити рівні лояльності (Стандарт: 5%/20%/14д/4міс)
5. Підключити підписки на події `ЧекККМ` та `ВозвратТоваровОтПокупателя`
6. Увімкнути регламент `LC_АктивацияИСгораниеБонусов` о 00:00
7. Запустити міграцію клієнтів
